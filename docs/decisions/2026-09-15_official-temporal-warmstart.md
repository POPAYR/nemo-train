# 决策记录：用官方 ε temporal module 热启动 —— **否决**

**日期** 2026-09-15 ｜ **状态** 已验证否决 ｜ **触发** 生成视频头发闪烁，怀疑时序模块训练量不足

---

## 1. 假设

ε teacher（官方 XNeMo）生成的视频头发运动"幅度小但自然"，我们从零训的时序模块则
"幅度过量且不连贯"（头发区帧间变化 2.5×GT，ε teacher 0.5×GT）。

猜想：官方 `xnemo_temporal_module.pth`（588 张量，1.82GB，在 HDTF+VFHQ+NerSemble 上训到收敛）
里编码了"头部大幅运动时头发怎么飘"的先验，拿它热启动能跳过我们从零学的漫长过程。

**支持性证据（当时看来很强）**：
- 546/546 个可训练张量与我们的模型 100% 对得上、形状全一致；
  官方多出的 42 个是 `*.pos_encoder.pe`（加性 PE 缓冲区），我们用 RoPE 本就不需要
- 我们的 stage1 主干相对官方 ε 权重的**漂移中位仅 0.90%**（p90 6.6%），
  据此推断"特征空间基本没变，注意力先验应可迁移"

## 2. 三条对照线（起点严格对齐，同主干/同数据/同超参）

| step | A 随机初始化 | B 官方直灌 | C 官方 + proj_out 清零 |
|---|---|---|---|
| 0 | 0.22980 | **0.49751** | 0.22980 |
| 200 | **0.19485** | 0.21852 | 0.21834 |
| 400 | **0.18100** | — | 0.20172 |

其他指标（step 400，C 线）：`DYN=4.281`（A 在 step 500 已收敛到 1.082）、`FLK=2.375`。

- **B（直灌）**：step 0 即失控 —— vmse 0.498 **比完全没有时序模块的 0.231 还差一倍**，
  `DYN=160×`、`FID=379`。因为官方 `proj_out` 非零，一加载就往主干注入
  按 ε 空间尺度算出的强信号；而随机初始化那条路 `proj_out` 是零初始化（起点=恒等）。
- **C（清零 proj_out）**：起点回到恒等（vmse 与 A 逐位相同），但 200/400 两个点
  **稳定落后 A 约 11~12%**，且 `DYN` 仍卡在 4.3×，无收敛迹象。

## 3. 结论与失败原因

**否决。** 官方注意力先验在 v 空间主干上不但没有帮助，反而是负担：
C 从恒等起步、只需学 `proj_out`，按理该远快于连注意力都要从零学的 A，实际却更慢。
合理解释是 `proj_out` 被迫去适配一套**方向就不对**的注意力输出，难度高于让两者一起从零学。

B 能在 200 步内从 0.498 恢复到 0.219，起初被误读为"先验在起作用"；
实为模型在**快速改写**官方权重 —— 其梯度范数 0.54~0.62，是 A 线同期（0.1~0.3）的两倍多，
那是纠错的力度，不是学习的力度。

### ⭐ 教训：权重距离小 ≠ 功能等价

"主干漂移中位 0.90%" 被用来推断"特征空间基本没变"，这一步是错的。
时序模块跨帧做注意力，对中间层激活的**方向结构**敏感；
ε→v 的参数化改写虽只大幅改动少数层（max 漂移 187%，多为输出层附近），
却足以让激活的方向分布改变，令官方注意力模式失效。
**判断可迁移性要看功能等价（如激活相关性），不能只看参数 L2 距离。**

## 4. 影响

- 回到 A 线（随机初始化 + `proj_out` 零初始化）继续训，已有 `s2_long2/stage2_step_2000.pt`（累计 4500）
- 附带确认：`--zero_proj_out` 开关已加进 `flow_stage2_temporal.py`，
  将来任何"用外部 temporal 权重热启动"的尝试都应默认开启，否则起步即失控
